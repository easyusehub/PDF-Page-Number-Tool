🧩 How to Use

Click Upload PDF and choose your file.
Use the checkbox list to select pages for numbering.
Type a number into the input and press Add Number to assign it to selected pages.
Optionally click Auto Number Selected Pages to apply sequential numbering.
Edit numbers live if needed.
Click Download PDF to get the newly numbered file.
